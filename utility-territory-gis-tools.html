Home

One foundational national dataset (HIFLD) covers all 50 states and is what most other tools are built from. State-maintained tools layer on top and are usually more current and authoritative within their state. For any state without a dedicated tool, the national HIFLD / EIA layer already covers it.

Boundaries on essentially every source are approximate and illustrative, not survey-grade — the serving utility confirms edge cases. ORNL’s openenergyhub copy shows “does not exist anymore” (Mar 2026), but the HIFLD and EIA hosted copies remain live.

Notes for the Lookup Tool

Universal basemap

Keep the national HIFLD / EIA feature layer as the default — it underlies the NREL API + Census geocoder lineage already in use.

Easiest state overrides

Queryable ArcGIS REST endpoints: NJ, NY, OH, WA, MI, MN, IN, IA. Wire these in first as overrides on top of HIFLD.

Authority wins

Statutory “map of record” states (MN, OH, IA, IN, NE) should override HIFLD when they disagree.

PNW QA cross-check

The NW Clean Energy Atlas documents known EIA territory errors (e.g., Tacoma Power, Benton REA) — handy for home-region lookups.
